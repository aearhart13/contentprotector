What happens during a scan

  1. Searches YouTube for channels using these queries:
    • "Ryan Hall Y'all"
    • "Ryan Hall Yall weather"
    • "Ryan Hall storm chase"
    • "Ryan Hall" weather channel
    • "Ryan Hall tornado"
  2. Fetches full details for each discovered channel
  3. Extracts features: name similarity, description text, avatar image, account age
  4. Scores each channel using {% if model_exists %}the trained ML model{% else %}heuristic weights{% endif %}
  5. Channels scoring above 45% are flagged for review

Each scan uses approximately 600–800 YouTube API quota units (free tier allows 10,000/day).
